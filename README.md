# Inventory Management Application

A desktop-based inventory management application developed using Visual Basic .NET (VB.NET) during an internship at PT Seiwa Indonesia.

## Project Overview

This project was developed to support IT inventory management through a desktop application.

## Technologies Used

- Visual Basic .NET (VB.NET)
- Windows Forms
- MySQL
- MySQL ODBC Driver
- Microsoft Visual Studio

## Key Features

- View inventory records
- Add inventory items
- Edit inventory information
- Delete inventory records

## Project Type

Internship Project

## Notes

This repository is intended for portfolio and educational purposes. Database credentials and confidential company information must not be included.

## Setup

1. Install the required version of Microsoft Visual Studio.
2. Install the required .NET Framework and MySQL ODBC Driver.
3. Configure a local MySQL database using an approved sample database.
4. Update the database connection settings.
5. Open `CRUDinventory.sln` in Visual Studio and build the solution.
